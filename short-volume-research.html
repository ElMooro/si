Daily short-sale volume describes reported executions. It does not establish outstanding short interest, days-to-cover, squeeze potential or whether traders covered positions.

History groups the same literal source symbol. Security identity through ticker changes or corporate actions is not verified; a continuous symbol is not proof of a continuous investment.

Inspect a daily observation

Short volume includes the short-exempt subset. The denominator covers FINRA-disseminated regular-session TRF/ADF volume in exchange-listed securities, not consolidated all-market volume. Shares retain their reported decimal precision.

Compare with complete prior windows

Each window uses the preceding 5, 20 or 60 published files and excludes the latest observation. These are file counts, not an assumed trading calendar. Selecting an older daily observation does not change the latest-based comparison.

Definitions and missing observations

The daily mean gives each valid daily percentage equal weight. The pooled ratio divides summed short volume by summed reported total volume. Sample standard deviation uses N−1. A z-score is a descriptive standardized difference, not a probability or return forecast. A missing row invalidates the declared window; a zero denominator invalidates daily-ratio statistics.
