How to interpret and reproduce this evidence

The observation date describes the economic measurement. A provider archive interval describes when the provider recorded that value as valid. Retrieval time describes when JustHodl captured the original response. These clocks serve different purposes.

Values retain their original decimal text and dated unit definition. A missing latest observation stays missing. A query-clipped interval start is not presented as an initial release. Frequently revised series load one bounded archive segment at a time.

The page verifies the immutable output hash before displaying it. “Verify original value and definition” independently checks the two retained response hashes, request identities, original observation row and full historical definition. This is content verification, not a claim of a provider digital signature or a qualified investment model.

Each replay manifest identifies the reviewed compiler and every original input. The repository command python scripts/replay_fred_vintage.py SERIES --collection COLLECTION_SHA rebuilds the selected collection’s archive from retained originals. It refuses a mismatched local compiler. Use the release containing that compiler; never execute downloaded source automatically.
