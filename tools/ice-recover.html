ICE BofA history recovery

Reads pre-truncation FRED history from the Wayback Machine and banks it to your S3. This page runs on your own origin — archive.org's replay wrapper can't rewrite the upload from here.

Step 1 — on an archive.org page, run the grabber script (it saves jh-ice.json).
Step 2 — choose that file here. Archive reads only work on their pages; uploads only work off them, so the file is the bridge.
