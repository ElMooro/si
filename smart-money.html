What these measurements mean

Jaccard overlap is the number of shared positive-quantity identities divided by their union. Manager coverage divides that same shared count by each manager's set size. Empty denominators are unavailable. Percentages round to six decimal places; the integer counts are retained.

The identity is the exact reported CUSIP, class, SH/PRN and PUT/CALL. Class spelling can split an economic security. Shares, option-underlying quantities and principal amounts remain in separate scopes. Zero-quantity rows remain visible but do not enter the positive-quantity overlap sets.

Shared discretion, manager relationships, confidential omissions, unreported shorts and different portfolio sizes limit interpretation. Set overlap is not a measure of portfolio correlation or diversification. No issuer-name guesses or legacy ticker mappings are used.
