Evidence and qualification

Current-vintage inputs, configured country weights, price adjustment and currency conventions, rolling standardization, release lags and missing data all require qualification. The model uses up to 120 valid prior observations, not necessarily 120 consecutive calendar months. Port-volume agreement is not independent predictive validation.
