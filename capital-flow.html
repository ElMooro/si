01 · PUBLIC MANAGER DISCLOSURES

Reconcile the change in reported value

For comparable non-option shares, the exact change separates into a quantity-associated term and an implied unit-value-associated term. A stock can rise in reported value while its disclosed share quantity stays unchanged.

Each scope reconciles independently. Matched change + newly present value − absent prior value = full table change. Rounded quantity and unit-value terms + rounding adjustment + changes not decomposed = matched change. Missing disclosures remain distinct from zero quantities.

Definitions and limitations of the value bridge

Let Q denote reported quantity and P denote reported USD value divided by that quantity. The quantity-associated term is (Q₁ − Q₀) × (P₁ + P₀) / 2. The unit-value-associated term is (P₁ − P₀) × (Q₁ + Q₀) / 2. Their sum equals the exact reported-value change.

P is an implied reported value per share, not a verified trade price. This arithmetic does not resolve stock splits, other corporate actions, changes in discretion, interim trading or confidential omissions. It is not causal price attribution. Unmatched identities, options, principal amounts, zero-quantity cases and unresolved source valuations remain visible without a fabricated decomposition.

The identity uses exact reported CUSIP, class, SH/PRN and PUT/CALL. There is no guessed ticker or cross-manager dollar total. Original fractions remain exact; displays use half-even rounding. Scope totals sum cent-rounded per-security terms with an explicit adjustment.
