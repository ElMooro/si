# Global Stress original-source research

The active Global Stress path is descriptive research. Its immutable run records
all original provider responses, complete credential-free request identities,
acquisition times, typed inputs, the exact compiler and the complete output. The
current public packet is accepted only after original-source replay. Publication
preserves the complete predecessor in the protected audit prefix and uses an S3
compare-and-swap so an older run cannot replace a newer one.

The 14 USD ETF proxies keep reviewed ISIN, exchange and currency identities.
FMP split-adjusted price and dividend-adjusted close are separate histories.
Neither is claimed to be an independently reconstructed executable total-return
series. The union of both date ledgers retains missing rows and original row
indices. Returns use 21/63 observed intervals with exact endpoints. Realized
volatility uses 20 observed log-return intervals, sample standard deviation and
the explicit square-root-of-252 convention. Drawdown uses 252 observations;
distance from the mean uses 200. Exchange-session completeness is not certified.

The 91 pairwise correlations match **both** endpoints of each adjusted log
return. The window covers the last 60 union observation end dates and requires
40 matched intervals with nonzero variance. No forward fill, row-position
alignment, causal contagion interpretation or trading probability is permitted.

Derived arithmetic uses a scoped 50-digit Decimal context with ROUND_HALF_EVEN,
including decimal logarithms and square roots. Exported derived measurements
round to 12 decimal places; original provider decimals remain unchanged. Replay
requires exact output equality and its complete hash, with no tolerance or
ignored fields. A fixed real-source fixture digest must match on Windows and
the Linux runner before publication. This policy prevents platform-specific
binary floating-point differences from breaking an otherwise identical replay.

Ten native FRED definitions bind identity, units, daily frequency, unadjusted
seasonality, current vintage and complete pagination. VIX remains index points;
Treasury yields and credit OAS remain percent. Yield/OAS changes convert to basis
points, while VIX changes stay index points. The 13-calendar-week comparison
requires the exact dated baseline. CCC-minus-BB OAS requires a same-date pair.
Current-vintage history does not establish what was available to a trader at a
historical decision time. Provider updated, observation, acquisition and output
timestamps remain separate.

The previous score, market ranking, horizon weights and causal labels confer no
authority. `gsi_authority.py` rejects self-asserted qualification and stale aliases
at direct consumer boundaries. Missing GSI contributes no vote or neutral score,
no allocator tilt/defensive override, no invented lead time, no drift against an
incomparable intraday score, and no automated GSI transition alert. Historical
GSI samples cannot re-enter the calibration fleet or redundancy clusters.

The existing calibrator and horizon schedules now publish qualification status
only, preserving complete prior reports. They do not train on the full sample,
write SSM weights or send notifications. Qualification requires a preregistered
target, point-in-time inputs, chronological held-out tests, horizon purging and
embargo, complete trial records, uncertainty, costs, regime coverage and reviewed
prospective shadow evidence. Existing SSM values are preserved but the native
producer never reads them.

The prior dimension-history ledger is preserved byte-for-byte as an audit
record. Current native histories live in immutable run outputs. The public
history pointer names that run; it does not relabel the legacy score series as
validated performance.

Acceptance checks the exact source commit in every function receipt, actual
deployed ZIP/source bytes, original-source replay, live built HTML/JS, no-store
publication and existing schedule bindings. Controlled invocation is restricted
to the public native producer and the two public qualification-status writers.
Portfolio, alert and narrative consumers are tested offline and deployed, not
invoked by acceptance. No private account reads, paid AI calls, portfolio writes
or messages are part of this upgrade.
