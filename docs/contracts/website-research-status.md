# Website research status

This replaces the paid website-synthesis path with an explicitly unqualified,
deterministic availability report. It is not a market thesis, prediction or
portfolio recommendation. The separate Calls brief producer is not changed.

The twelve existing input keys and their former field inventories are preserved
in `ENGINE_INPUTS`. Complete bounded received bodies replace prompt truncation.
Parsed artifacts are counted as parsed, never as fresh or independent votes.
Malformed, failed and missing inputs remain in the inventory. Donor eligibility
flags, market labels and text cannot grant authority or appear as a new thesis.
Observation and generation dates remain reported claims; unknown dates are null.
Every decision remains WAIT/abstain, every authority flag is false, and the
portfolio effect is null. Zero parsed artifacts describes acquisition results,
not zero risk or a neutral market.

The producer imports no model shim, router or secret loader. Its compatibility
model function raises; notification functions return unsent without reading or
writing prior alert state. Removing `inherit_env` from the deployment definition
stops copying an unused model key on future deploys; it does not claim existing
native environment values have been deleted. No credential value is inspected.
The previous source, configuration, widget and adapted tests are retained whole
under `tests/fixtures/website-research-status/pre513/`.

`context_evidence_store` retains complete donor bodies, acquisition attempts,
previous publication, compiler bytes and output under the protected prefix
`audit-private/20260909-originals/website-research-status/`. A conditional current
head write follows successful retention. A competing head, lost acknowledgement,
access denial or retention failure propagates instead of becoming successful
publication. The current key remains `data/ai-website-synthesis.json`. Existing
public hourly archives remain untouched; new replay records are content addressed
and protected. Public status exposes body digests and typed availability metadata,
not raw donor packets, raw exceptions or model prompts.

Exact retained donor bytes can support availability/abstention replay. This does
not establish original-provider measurement replay, independent evidence,
forecast performance, account reconciliation or suitable sizing. Actual normal
publication and access policy remain separate acceptance work. No private or
current application packet is read by the development or native release checks.

The widget accepts only the explicit status contract and false authority flags.
Old directional caches are withheld. Cache time must be finite, nonfuture and
within its local TTL; caching does not mutate a packet. Future/invalid publication
times remain visibly suspect. Request ownership prevents a late response from
replacing a newer result. Panel and button refresh together; failure, retry,
keyboard close/focus, mobile scrolling and literal text are covered by invented
whole-browser tests. Availability counts are inspectable with source keys and
body digests. They are not a measured market-coverage percentage.

The main module intentionally shrinks because paid HTTP, secret initialization,
market prompting and posture alerts are removed, and the pure compiler moves to
a bundled module. The complete related batch uses the deploy lane's documented
`[shrink-ok]` marker, retains the full predecessor and all former function names,
and tests the whole producer. It is not a truncated upload. Selected native
resources and the existing hourly :25 schedule must remain unchanged.

All institutional workstreams remain open. A research status report cannot
substitute for qualified source observations, a point-in-time outcome warehouse,
independent model review or reconciled portfolio consequences.

## Remaining contract-monitor migration

Source inspection found the legacy learned contract for this artifact still requires `error` and `snapshots`, including for the preceding successful producer shape. The current source-owned contract-gate overlay has no correction for this key. Stage 513 does not qualify that monitor or change its registry; its false structural alarms remain an explicit follow-up. No raw snapshots or invented error fields are added to satisfy a learned error-state schema. The public widget validates the new explicit research-status contract itself.
