# Chart labels stay text

Symbols, watchlist labels, notes, source captions and selected menu labels must not become executable HTML. The chart uses its existing HTML escaping helper at the reviewed text and quoted-attribute insertion points. Indicator UX uses the same escaping semantics for selected-symbol, timeframe and comparison labels. Identity and source values are retained; the display encodes ampersands, angle brackets and both quote characters. This does not validate provider identifiers or CSS values.

The complete offline predecessor reproduces DOM execution from a chart URL symbol on both desktop and mobile. The harmless invented payload sets only a DOM marker. Eight focused renderer cases also fail against the predecessor. The candidate must retain literal note values, both URL and hash entry paths, special characters in IDs, tab navigation, alert deletion and comparison removal. Every browser request is intercepted; no actual application data or actual-site execution is used.

Preservation gates bind all 21 reviewed engine functions, every unrelated function and outer statement, and the complete indicator UX file. Indicator UX changes only one helper and three display substitutions. Earlier assertions remain with only the actual escaping dependency and a hash-bound adapter. Related engine and UX files ship atomically.

This is a bounded repair, not a complete security audit. Other pages, URL construction, CSS values, drawing/annotation labels and third-party modules remain unqualified. Source acquisition, timeframes, calculations, polling, native functions and schedules are unchanged. This grants no Calls, model-validation, portfolio or sizing authority. All ten institutional workstreams remain open.
