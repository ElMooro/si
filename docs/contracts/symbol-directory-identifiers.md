# Symbol-directory identifier evidence

The directory retains primary reference instruments when optional symbology is
missing or malformed. It no longer copies a flat ISIN into the index by ticker
alone. The compatibility field remains null. Selected reported values, clocks,
character-pattern checks, source key, ticker and issuer consistency are separate
identifier_evidence. Even matching CIKs establish issuer consistency only. No
checksum, current security relationship, independent source replay or automatic
identifier routing is certified. The source's qualification boolean is a reported
claim, not permission. Unbounded/nonfinite malformed values are withheld with
their type recorded; this selected metadata is not a whole-source archive.

Native doc_row already excluded the stored ISIN and still does. The independent
chart catalog reads the master directly. Its exact ticker lookup preserves dots
and hyphens and rejects ambiguous case-colliding rows. ISIN/CUSIP/FIGI candidates
remain searchable with an explicit unverified label, but lookupSym/chartId no
longer convert an identifier to the first matching ticker. Identifier-like searches require explicit arrow-key or pointer selection; exact
unique catalog tickers retain direct Enter navigation. Raw identifier-like strings
are not offered as direct ticker entries. Chosen rows follow their identity when
asynchronous results reorder. This does not certify instrument identity or
prevent a user from explicitly choosing an unqualified candidate. Existing qualified provider namespaces remain.

Complete predecessor native and catalog sources, full invented input populations,
all generated compressed bodies and reproduction results remain in fixtures.
Whole native replay compares decoded structures and validates each manifest's
byte accounting against its own retained/generated bodies; hash-seed-dependent
pickle ordering can change compressed size. Environment-specific traceback text
is handled separately while original full traces remain retained.

The engine runner includes the pre-existing fiscal, provider-search and warehouse
suites plus identifier model and whole native build regressions. Real HTTP is
blocked in tests. Read-only operations 6403/6404 compare package bytes, receipt,
resources and all seven original Scheduler bindings without invoking the native
producer or reading current/private/account/consumer artifacts.

Mixed docs/index generations and forced-refresh cache loss are reproduced and
remain separate repairs. Build completeness, inherited input-read failure
conflation, independent real-source replay and normal new-code publication are
not accepted by this scope. The chart search renderer escapes source names, metadata, identifiers, facets
and empty-query text. Invalid facet counts stay unknown. Old-query requests and
timers cannot overwrite a newer short query. Complete offline browser cases
verify search at 1440 and 390 pixels with invented sources and an inert chart
library; chart drawing and other removed scripts are outside that test scope. No investment, portfolio sizing or institutional completion is
claimed by these changes.
