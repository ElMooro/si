# Term Premium public original-archive acceptance

Operation 6376 is read-only. It compares the complete native runtime before and
after acquisition with the accepted September 28 package, resources and original
schedule. The release receipt must match commit
`33a552073789abd27609e307209077a6c84c8407`. The configured publication bucket is
checked without emitting unrelated environment values.

The archive adapter accepts only content-addressed objects under
`data/term-premium-research/`. It never reads the current public packet, private
predecessor/journal, account or downstream consumer. It never invokes a producer,
probes a provider, writes to AWS or changes schedules.

Both complete run inventories and every SDK listing page are retained. Missing
pagination evidence, duplicates, unexpected paths, invalid sizes, same-clock
conflicts, future clocks and inventory changes refuse acceptance. The 4,096-run
bound fails rather than accepting a sample. Complete bytes must match their
content address. All original run manifests are retained in the report.

If a run acquired after the accepted repair exists, the latest such run is
replayed through the current reviewed compiler. Every archived compiler, original
workbook cell, normalized input, output table and compact view participates in
the existing strict replay. Archived code is never executed. Empty or older
archives remain explicitly pending. Research authority remains false.

The committed runner report retains complete inventories, manifests, artifact
identities, native runtime observations and replay results. SDK timestamps retain
their original datetime type marker and timezone. A successful replay proves
retained computation. It does not prove current-pointer advancement, schedule
causation, first-release availability, predictive validity or portfolio authority.

Nine whole invented cases cover complete replay, corruption, changed inventory,
scope isolation, pending archives, pagination, conflicting clocks, typed runtime
identity and environment-value minimization. Native model tests remain unchanged.
