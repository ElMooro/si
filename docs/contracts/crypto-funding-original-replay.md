# Crypto funding original replay

The producer stores original response bytes (or an explicitly incomplete prefix), every attempted request, its acquisition clock, deterministic descriptive output and both local compiler files. Each object is addressed by its complete SHA-256 under `data/crypto-funding-research/`; no mutable latest pointer is used. A complete run manifest references the capture and compiler objects. Conditional writes and full readback detect conflicting or truncated storage. This is application-level immutability, not S3 Object Lock or protection against privileged deletion.

Only the fixed OKX/Bybit public requests already used by this collector are retained. No account, private, current consumer packet, prompt or paid model participates. Replay checks the complete attempt universe, order, response hashes, whole parser outputs, exact event basis, acquisition interval and whole public projection. It reads matching compiler bytes for verification but never executes downloaded code. Use the reviewed checkout whose compiler hashes match the manifest; an updated compiler refuses an older manifest rather than silently rewriting history.

The engine publishes new descriptive funding only after complete original retention and replay. Storage, compiler, budget or replay failure withholds that section. Storage uses two-second connect and three-second read timeouts without automatic retries, checks remaining Lambda time before every call and read chunk, and reserves thirty seconds for remaining work. These are safeguards, not an end-to-end execution SLO; other existing tasks remain separately unqualified. Provider request count, endpoints, schedules and resource controls are unchanged.

The manifest and packet keep investment, sizing, execution, source-timing and point-in-time qualifications denied. A stored response is evidence of what was received, not proof of economic truth, source freshness, realized carry, prediction skill or portfolio suitability. Exact deployment acceptance is separate from observing normal original publication. Public archive discoverability and page inspector links are a following step after storage evidence exists.
