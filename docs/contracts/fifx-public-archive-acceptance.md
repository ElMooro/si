# FI/FX complete original archive acceptance

The read-only 6378 operation verifies the complete native package, exact release receipt, unchanged resources and original weekday 21:20 UTC schedule before and after replay. It reads only the precise release receipt and content-addressed public FI/FX originals and canonical FRED dependencies. Current publication pointers, private journals, account data and downstream consumers are excluded before storage access. It performs no provider request, native invocation, object write or schedule change.

Every page and entry of the native run inventory is retained. The exact prefix, declared counts, terminal listing page, unique identities, whole manifest bytes and explicit UTC clocks are checked. Same-clock conflicts, future runs, changing inventories and more than 4,096 runs fail without accepting a subset. No post-repair archive produces an explicit pending result rather than a publication claim.

The latest retained post-repair run is reconstructed from its whole immutable view and all current reviewed compilers. Canonical FRED definitions and observations replay from their pinned original responses. All 18 source originals, receipts, independent proofs, complete history shards and compact summaries replay. No archived source code is executed. Binary reads run to EOF, close on failure and verify the declared complete stored length; gzip container identity and decoded provider identity remain distinct.

Replay integrity and source recovery are separate. The report preserves every source identity, quality assessment, original/history row count, receipt clock, expiry, complete artifact reference and acquisition status. Missing sources and rejected MOVE identity remain unavailable. The availability count applies only at the original run clock. A retained original run does not prove current publication, scheduler causation, first-release availability, predictive edge or portfolio authority. WAIT, null call/regime, unavailable target weights and every false authority flag remain required.

Tests construct whole invented canonical responses and all 18 complete native inputs. They cover complete replay, missing sources, wrong MOVE identity, corrupt originals/compiler/gzip, short stream reads and closure, declared lengths, empty/pre-repair inventories, duplicate/future/conflicting clocks, inventory changes, scope enforcement and exact typed runtime settings. Native arithmetic and acquisition tests remain required. The live runner report is the acceptance evidence; green code tests alone are insufficient.
