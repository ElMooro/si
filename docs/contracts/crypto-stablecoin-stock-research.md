# Reported stablecoin stock research

The reviewed public provider source values current and prior circulating quantities using its selected current price or fiat FX fallback. Prior day, week and month are provider labels; the endpoint does not return the chosen observation timestamps. These are descriptive stock snapshots, not cash transactions, net capital inflows, mint/burn events or historical market values. All returned rows, declared peg types, missing values and provider flags are retained. No unweighted name-count vote or global total is inferred. Real zero survives; missing and malformed values remain unavailable. Zero prior stock leaves percentage comparison unavailable. Full decimal operands, differences and percentage rounding are explicit.

Only the existing public endpoint is requested, once, with its existing timeout. Whole bounded original response bytes (or a labelled incomplete prefix), acquisition clocks, parser result and three reviewed compiler files are stored under content-addressed `data/crypto-stablecoin-research/` paths. Conditional writes and complete readback precede replay and descriptive publication. This is not Object Lock. The parser refuses a population exceeding 5,000 rows as a whole and retains its original bytes; it never quietly publishes a truncated subset. Body and row limits are safeguards, not a latency or memory SLO.

Compiler verification never executes downloaded code. Consumers recompute the whole original projection before accepting a descriptive stock count, with stored archive availability still explicitly unverified there. All Calls, sizing, execution, forecast, source-authenticity and point-in-time qualifications remain denied. Missing storage or remaining execution budget withholds new stock output. Existing resource controls and schedules remain unchanged. The page displays all rows, original pointers, quantity basis and missing dates; legacy flow labels are unavailable. Exact native deployment, public static bytes and normally produced original replay each require separate evidence.

The source-definition review is pinned to the [provider tree](https://api.github.com/repos/DefiLlama/peggedassets-server/git/trees/43ea0e28655f7391e57ac687f84377c0bcf8a39a), the [complete snapshot compiler blob](https://api.github.com/repos/DefiLlama/peggedassets-server/git/blobs/f8e023a7ed6fc12a85d6b183d37f49358f85fa3d) and the [complete route blob](https://api.github.com/repos/DefiLlama/peggedassets-server/git/blobs/86671e4953420d3841e409587657121a212dbfe8). Whole Git object identities and SHA-256 values were checked. The provider’s deployed revision is unknown; reviewed source code does not prove deployed behavior.

Read-only original acceptance lists the complete bounded run namespace before and after inspection, verifies every referenced object’s complete bytes and content address, checks acquisition/storage clocks, and replays with matching reviewed local compilers. It checks the exact release receipt before and after. Missing matching originals remain pending; replay does not assert current publication, source authenticity, schedule causation or investment authority. No producer invocation or provider probe is part of acceptance.
