# Reviewed IMF chart histories

This candidate exposes 10,113 exact public series in IMF labour statistics, production indices, producer prices and monetary/financial interest rates. Each definition pins the dataflow version, complete dimensions, SCALE=0, index reference base, methodology and group metadata. It does not qualify monetary amount scales, non-public observations, proprietary vendor equivalence or historical release-time vintages.

Only complete single-series official SDMX responses are accepted. Original responses, metadata, exact decimal values and observation flags remain traceable. Unknown definitions, changed units, partial responses, invalid access labels, failed retention and HTTP refusals return an unavailable result. Shared daily claims prevent duplicate source acquisition; a refusal stops the source until reviewed. There is no fallback to a differently defined instrument.

Sixty-eight watchlist identifiers receive explicitly unqualified source alternatives. The requested identifier, resolved IMF series, unit and last source observation remain visible. A monthly policy-rate history is not a live central-bank decision. Published growth series retain their own adjustment and methodology; missing values are not zeros and forecasts are not historical observations. Binary64 chart coordinates disclose rounding while preserving original decimal text.

Offline replay and intercepted browsers are preliminary checks. AWS acceptance requires the exact source receipt and whole native file hashes with unchanged controls, then live public directory/history/source replay and commit-bound served chart verification. Catalogue membership alone is not live historical coverage. No Calls, sizing or trading authority is granted by these routes.
