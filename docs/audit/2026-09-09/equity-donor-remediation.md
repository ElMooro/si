# Equity, sizing and cross-market donor remediation — 9 September 2026

The integrations distinguish a dated observation, a model estimate, a research ranking input and an execution requirement. Loading a donor is not evidence that it establishes executable liquidity or investment skill. This document covers D15–D34; D32 is implemented and documented in the accounting agent's liquidity-capacity work.
