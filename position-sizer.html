PORTFOLIO RESEARCH / EXPLICIT SCENARIOS

What would these assumptions do to a portfolio?

Enter signed exposures and price shocks to reconcile position P&L, currency effects, cash, financing and costs. Every result retains its exact inputs and calculation. The old score-to-allocation rule has been retired.

Inputs stay in this page's memory. Export downloads them only when you choose. This tool does not load accounts, send positions to a server, recommend weights or place trades.

Model scope

Static cash securities, including signed short exposure, over one explicit horizon. FX means the change in the base-currency value of one unit of the position currency. Use zero FX for a position already denominated in the base currency.

Read assumptions and exclusions

Residual cash equals 100% minus net security weights. Positive residual cash receives the entered cash rate; negative residual cash pays that same entered borrowing rate. Enter a rate for the stated horizon, not an annual rate. Short proceeds are assumed fully available: segregation, collateral, margin calls and intraperiod liquidation are not modeled. Include assumed borrow fees, trading costs and other expenses in aggregate costs.

Price shocks exclude dividends and coupons. Options, futures, default recovery, nonlinear payoffs, path dependence, probabilities and expected returns are outside this model. Currency codes are your labels, not verified instrument mappings. No missing input defaults to zero. The 1000% gross computation bound is not an approved risk limit.

Base return = (1 + local price return) × (1 + FX return) − 1. Position impact = signed NAV weight × base return. Total impact = position impacts + residual cash/financing − costs. Currency amounts display two decimals; exact fractions remain in the export.
